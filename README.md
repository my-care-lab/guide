# MCL-A1 설치 및 사용 가이드

MCL-A1(MyCareLab)은 스마트폰의 센서 데이터를 수집해 하루 생활을 분 단위로 기록하고,
그 패턴 위에서 건강 목표(체중·활동·수면·디지털·식이·마음건강)에 맞는 **실천 미션**을
상황이 맞는 순간에 카드·알림·음성·코치 전화로 제안하는 Android 앱입니다.

이 문서는 앱을 **설치하고, 처음 설정하고, 일상적으로 사용하는 방법**을 안내합니다.

---

## 1. 설치

이 앱은 **앱스토어(Play 스토어)에 등록되어 있지 않습니다.** 전달받은 APK 파일을
직접 설치해야 하며, 그 과정에서 나오는 보안 안내는 스토어 외 설치라 뜨는
정상적인 절차이니 아래처럼 진행해 주세요.

1. 전달받은 `mcl-a1-*.apk` 파일을 폰에서 연다 (카톡·메일로 받았다면 파일을 탭).
2. **"출처를 알 수 없는 앱을 설치할 수 없음"** 안내가 나오면
   **설정 > 이 출처 허용**을 켜고 돌아와 다시 설치를 진행한다.
3. "이 유형의 파일은 기기를 손상시킬 수 있음" / Play Protect 경고가 떠도
   **무시하고 설치**를 선택한다.
4. 업데이트할 때는 새 APK 파일을 같은 방법으로 열어 설치하면 되고,
   기존 데이터는 유지된다.

요구 사항: **Android 8.0 이상** (미션 전체 기능은 Android 14 권장).
Health Connect(삼성헬스·워치 연동)는 선택 사항으로, 없어도 앱은 동작합니다.

---

## 2. 사용 전 참고사항 (제약)

- **위치 조회·날씨 API는 호출 건수 제한이 있습니다.** 제한(limit)에 걸리면
  장소 이름·날씨 조회가 일시적으로 실패할 수 있습니다 (시간이 지나면 회복).
- **약 2주 데이터를 축적해야 사용자의 생활 패턴이 파악됩니다.** 그 전에는
  패턴 기반 개인화가 완전하지 않아 **나와 관련 없어 보이는 미션이 있을 수
  있습니다.**
- **스파르타 코치 선택 시**, 미션에 무응답하면 **실제 전화가 오는 것처럼 착신
  화면과 진동이 동작**합니다. 놀라지 않도록 미리 참고해 주세요.
  (코치의 전화 음성을 들으려면 **미디어 사운드가 켜져 있어야 합니다**)
- **현재는 목표를 1가지만 등록해 주세요.**

## 3. 처음 설정 — 필수 권한 켜기

앱을 처음 열면 **시작 화면**에 필수 설정 목록이 나옵니다. 각 항목은 현재
상태를 스위치로 보여주고, 누르면 해당 권한 요청 또는 시스템 설정 화면으로
이동합니다. 설정을 마치고 돌아오면 상태가 자동 갱신됩니다.

위에서부터 순서대로 켜 주세요:

| 항목 | 하는 일 | 필수 여부 |
|---|---|---|
| **기본 권한 (활동·위치·알림)** | 걷기/차량 등 활동 인식, 위치 기록, 미션 알림. 위치는 "항상 허용"까지 켜야 화면이 꺼진 동안에도 기록됩니다 | 필수 |
| **사용 정보 접근** | 어떤 앱을 얼마나 썼는지 기록 (화면 사용·시청 인식). 설정 > 특별한 앱 액세스에서 직접 허용 | 필수 |
| **다른 앱 위에 표시** | 다른 앱 사용 중에 미션 카드를 화면 위 배너로 띄움 | 필수 |
| **전체 화면 알림 (코치 전화)** | 고강도 미션 무응답 시 잠금화면 위로 코치 전화 화면을 띄움 (Android 14+에서만 설정 필요) | 권장 |
| **알람 및 리마인더** | 잠금 상태에서도 코치 전화가 정시에 울리게 하는 정확한 알람 | 권장 |
| **건강 데이터 연결 (워치 걸음·수면)** | Health Connect에서 체중·걸음·수면·운동을 읽어 옴 (삼성헬스 등과 동기화) | 선택 |

### 위치 "항상 허용" 설정 팁

Android 10 이상에서는 위치 권한을 먼저 "앱 사용 중에만 허용"으로 준 뒤,
백그라운드 위치 요청이 한 번 더 뜹니다. 여기서 **"항상 허용"** 을 선택해야
주머니에 넣어 둔 동안에도 이동이 기록됩니다.

### 건강 데이터 연결이 안 될 때

권한 요청 창이 뜨지 않고 바로 닫히면, 이전에 2회 거부해 시스템이 요청을
차단한 상태입니다. 이때는 앱이 Health Connect 설정 화면을 열어 주므로 거기서
직접 허용해 주세요. 연결되면 최근 30일 데이터를 한 번 동기화하고, 이후에는
자동으로 3일 단위 증분 동기화합니다.

### 기록 시작

권한을 켰으면 **[기록 (활동·위치·화면 사용)]** 스위치를 켭니다. 상시 실행되는
수집 서비스가 시작되며 알림 표시줄에 수집 중 알림이 상주합니다
(배터리 최적화 대상에서 제외해 두면 기록 누락이 줄어듭니다 —
설정 > 배터리 > 백그라운드 사용 제한 없음).

기록은 같은 스위치로 언제든 중지할 수 있습니다.

## 4. 목표 등록

시작 화면의 **[목표]** 를 누르면 목표를 등록·관리할 수 있습니다.
등록은 4단계 위저드로 진행됩니다.

> **현재는 목표를 1가지만 등록해 주세요.** (여러 목표 동시 운용은 준비 중)

### 4.1 등록 4단계

1. **도메인 선택** — 어떤 영역의 목표인지 고릅니다.

   | 도메인 | 목표 수치 |
   |---|---|
   | 체중 | 목표 체중 (kg) |
   | 신체활동 | 7일 평균 걸음 수 |
   | 수면 | 7일 평균 수면 시간(분) |
   | 디지털 | 7일 평균 화면 사용 시간(분) |
   | 식이 | 수치 없음 — 미션 수행 중심 |
   | 마음건강 | 수치 없음 — 미션 수행 중심 |

2. **목표 수치 입력** — 현재값(측정 기록이 있으면 자동 표시)을 참고해 목표값을
   넣습니다. 식이·마음건강은 이 단계를 건너뜁니다.
3. **기한 설정** — 언제까지 달성할지 정합니다 (무기한도 가능).
4. **코치 선택** — 이 목표의 미션을 만들 때 기준이 되는 **안내 강도**입니다.

   | 코치 | 강도 | 특징 |
   |---|---|---|
   | 스파르타 코치 | 3 | 단호한 안내 — 무응답 시 **코치 전화**(착신 화면·진동)가 오는 미션 위주 |
   | 밸런스 코치 | 2 | 보통 톤의 미션 위주 |
   | 힐링 코치 | 1 | 부드러운 권유 미션 위주 |

같은 도메인의 활성 목표가 이미 있으면 교체(기존 목표는 보관)를 제안합니다 —
상충하는 목표가 쌓이지 않게 하기 위함입니다.

### 4.2 미션 생성

목표 등록을 마치면 **"미션을 만들까요?"** 팝업이 뜹니다. **[만들기]** 를 누르면
LLM이 내 생활 패턴(2주 프로필·인사이트·실제 방문 장소)을 바탕으로 목표에 맞는
미션들을 생성합니다 — 수십 초 걸릴 수 있습니다. [나중에]를 눌러도 이후 자동
재계획 때 만들어집니다.

### 4.3 목표 변경·삭제

[목표] 메뉴에서 목표를 누르면 현재 수치·코치·일정이 보이고, 그 자리에서
**변경**(위저드 재실행) 또는 **삭제**할 수 있습니다. 삭제하면 목록에서 사라지고
그 목표의 미션 알림이 중단됩니다 (기록 이력은 보존).

## 5. 미션 — 알림을 받고 실천하기

### 5.1 내 미션 확인

시작 화면의 **[미션]** 을 누르면 지금 활성 목표에 속한 오늘의 미션이
우선순위 순(위일수록 먼저 안내)으로 나옵니다. 항목을 누르면
**언제 알림이 오는지**(발화 조건)와 **무엇을 하면 완료인지**(완료 기준),
완료 점수를 자세히 볼 수 있습니다.

### 5.2 미션 안내가 오는 방식

미션은 상황이 맞는 순간(예: 기상 직후, 걸음이 부족한 저녁, 영상 60분+ 시청 중)에
자동으로 안내됩니다:

- **화면을 보고 있을 때** → 다른 앱 위에 배너 카드로 표시
- **화면이 꺼져 있거나 다른 상황** → 알림으로 전달
- 같은 문구를 **음성(TTS)** 으로도 읽어 줍니다
- **강도 3 미션**(또는 스파르타 코치 목표)은 무응답 시 **코치 전화**로 한 번 더
  안내합니다 — 실제 전화처럼 착신 화면이 뜨고 진동이 울립니다.
  전화 음성은 미디어 사운드가 켜져 있어야 들립니다.

### 5.3 미션에 반응하기

안내 카드/알림에서 고를 수 있는 반응:

- **할게요** — 미션을 수행하겠다는 응답. 체중 미션이면 바로 입력 창이,
  스쿼트 미션이면 횟수 카운터가 열립니다.
- **다른 미션** — 지금 미션 대신 다른 것을 제안받습니다.
- **나중에** — 잠시 미룹니다.
- **무시(스와이프)** — 반응하지 않고 넘깁니다.

모든 반응은 기록되어 이후 미션 개인화(자주 무시하는 미션은 덜 제안 등)에
반영됩니다.

### 5.4 완료 판정과 점수

미션 완료는 대부분 **자동으로 판정**됩니다:

- **걷기 미션** — 실제 걷기 기록(걸음·이동)과 대조해 판정
- **체중 측정 미션** — Health Connect 체중 기록 또는 직접 입력으로 판정
- **스쿼트 미션** — 화면 카운터로 횟수를 보고 (일부만 해도 부분 점수)

완료하면 미션별 점수가 적립됩니다.

## 6. 생활 타임라인

앱이 데이터를 충분히(약 2주) 모으면, 수집된 기록을 바탕으로 나의 **전형적인
하루 타임라인**(평일/주말 각각)을 LLM이 요약해 줍니다 — 언제 자고 일어나는지,
언제 출퇴근하는지, 어디에 머무는지, 화면을 얼마나 쓰는지를 서술과 시간표로
보여줍니다. 이 프로필이 미션의 "상황 인식"의 기반이 됩니다.

집(HOME)·회사(WORK)는 장기 체류 패턴에서 **자동으로 라벨링**되며, 별도 입력이
필요 없습니다.

---

## 7. 데이터와 개인정보

- 모든 원시 데이터(활동·위치·화면 사용·건강 지표)는 **기기 안의 로컬 DB**에
  저장됩니다.
- 외부로 나가는 것은 LLM 요약을 위한 **통계 프로필**(압축된 생활 패턴),
  날씨 조회를 위한 대략적 위치, POI 조회를 위한 체류지점 좌표뿐입니다.
  이동 경로 전체가 외부로 전송되지 않습니다.
- 원시 이벤트는 90일, 분 단위 이력은 180일 보존 후 자동 정리됩니다.

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 미션 알림이 안 옴 | [미션]에 미션이 있는지 → 목표 등록·미션 생성 여부. 알림 권한, "다른 앱 위에 표시" 허용 여부 |
| 밤/이동 중 기록이 비어 있음 | 위치 권한이 **"항상 허용"** 인지, [기록] 스위치가 켜져 있는지, 배터리 최적화에서 제외했는지 |
| 앱 사용 시간이 기록되지 않음 | "사용 정보 접근"이 허용돼 있는지 (설정 > 특별한 앱 액세스) |
| 걸음·체중이 동기화되지 않음 | 건강 데이터 연결 여부, 삼성헬스 → Health Connect 동기화 설정 |
| 코치 전화가 잠금화면에 안 뜸 | "전체 화면 알림"과 "알람 및 리마인더" 허용 여부 (Android 14+) |
| 코치 전화 음성이 안 들림 | **미디어 사운드**가 켜져 있는지 (무음·미디어 볼륨 0이면 진동·화면만 동작) |
| 장소 이름·날씨가 안 나옴 | 외부 API 호출 제한에 걸렸을 수 있음 — 시간이 지나면 회복됩니다 |
| 나와 관련 없는 미션이 나옴 | 데이터 축적 2주 전에는 패턴 파악이 완전하지 않아 있을 수 있는 현상입니다 |
| 재부팅 후 기록이 멈춤 | 앱을 한 번 열면 수집이 재개됩니다 (부팅 시 자동 재시작이 제조사 절전 정책에 막힐 수 있음) |
| 미션·타임라인 생성 실패 | 네트워크 연결 상태 확인 후 다시 시도 |
